# kiymet-site

Kıymet uygulamasının herkese açık web sitesi ve fiyat yayıncısı.

- `site/`: Destek ve gizlilik politikası sayfaları
- `feed/`: Fiyat yayıncısı (TCMB, TCMB EVDS, OECD, BIS; onaydan sonra CoinPaprika)
- Yayın adresi: `https://<kullanıcı>.github.io/kiymet-site/`, fiyatlar: `…/data/prices.json`

Veri kaynakları uygulamada ve sitede belirtilir. EVDS verileri TCMB'nin kullanım şartları gereği
kaynak gösterilerek kullanılmaktadır.
